# Банери на головній

Каруселька зверху головної сторінки. Поки в блоці немає жодного слайда —
секція автоматично прихована й на сайті нічого не видно.

## Розміри для дизайнера

| Версія | Розмір файлу | Пропорція | Де показується |
|---|---|---|---|
| Десктоп / планшет | **2640 × 600 px** | 22:5 | ширина екрана від 640 px |
| Мобільна | **1080 × 600 px** | 9:5 | ширина екрана до 639 px |

- Формат: JPG (фото) або PNG/WEBP (графіка, прозорість). Вага — до 300 КБ на файл.
- Кути банера обрізаються радіусом ~24 px — не ставте важливе впритул до країв.
- Безпечна зона: відступ **90 px** з усіх боків на десктопі, **50 px** на мобільній.
- Праворуч знизу на банер накладаються крапки-перемикачі, ліворуч і праворуч
  по центру — стрілки. Не розміщуйте там текст.
- Текст на банері має бути частиною макета: сайт свого тексту поверх не додає.

## Як додати банер

1. Покласти файли сюди: `assets/img/banners/`.
2. У `src/pages/index.html` знайти секцію `data-banners` і вставити всередину
   `[data-banner-track]` блок на кожен банер:

```html
<article class="w-full shrink-0" role="group" aria-roledescription="слайд">
  <a href="catalog.html" class="block">
    <picture>
      <source media="(max-width: 639px)" srcset="assets/img/banners/NAME-mobile.jpg" />
      <img src="assets/img/banners/NAME.jpg" alt="ОПИС БАНЕРА"
           width="2640" height="600" loading="eager" decoding="async"
           class="aspect-[9/5] w-full rounded-3xl object-cover sm:aspect-[22/5]" />
    </picture>
  </a>
</article>
```

3. Якщо банер без посилання — той самий блок без `<a>`.
4. Перезібрати: `npm run build:all`.

## Поведінка

- Автопрокрутка кожні 5 секунд, по колу.
- Пауза при наведенні миші, при фокусі з клавіатури та коли вкладка неактивна.
- Свайп пальцем на мобільній.
- Стрілки (з 1024 px) і крапки-перемикачі.
- Один банер — стрілки, крапки й автопрокрутка не показуються.
- При системному налаштуванні «зменшити рух» автопрокрутка вимкнена,
  гортання вручну працює.

`alt` у кожного банера обовʼязковий — опишіть, що на ньому зображено.
